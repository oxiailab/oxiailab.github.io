Починка звука и полного экрана в видео.

Меняются только шесть страниц кейсов, они лежат в корне.

1. На GitHub в репозитории: Add file -> Upload files.
2. Перетащи все шесть файлов case-*.html из этой папки в корень.
3. Внизу Commit changes. GitHub заменит старые новыми.
4. Открой сайт, зайди в кейс, нажми Ctrl и F5.
5. В видео нажми play: пойдёт звук. Кнопка полного экрана справа теперь работает.

Папки images и video НЕ трогаем, ролики и постеры уже на месте.
